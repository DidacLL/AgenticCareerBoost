# AgenticCareerBoost

AgenticCareerBoost is my personal career workspace and public proof record: an Astro-built static portfolio, public/general CV and report sources, and local scratch tooling.

- site/ — Markdown-authored Astro public site.
- agents/cv/ and agents/reports/ — public CV/report sources and publication tools.
- application-tracker/ — local scratch/prototype evidence and cover-letter workflow; it is not a public product surface.
- agents/state/, agents/rules/, and agents/tests/ — historical evidence, not current operating instructions.

Private application data, tailored materials, recruiter notes, databases, and generated private files remain local and untracked. The local letter workflow remains application-tracker/letter.ps1 <slug>.
