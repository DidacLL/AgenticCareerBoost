# agents/

This tree contains repository evidence, public/general CV source, report source,
historical working records, research, and a few local helper scripts from ACB's
evolution.

It is not a live agent harness. The active repository guidance is the root
`AGENTS.md` plus direct user instructions.

The root-level `acb_site_refactor_masterplan.md` and
`acb_site_refactor_tracker.md` in this directory are closed recovery records for
the 2026 site refactor. Their status blocks are evidence of that completed run,
not standing instructions for future agents.

## How To Read This Tree

| Path | Current role |
|---|---|
| `cv/` | Public/general CV LaTeX source and build support. |
| `reports/` | Formal report sources and historical repository evidence; not portfolio assets. |
| `rules/` | Legacy harness design kept as evidence of previous system thinking. |
| `state/` | Historical logs, research, decisions, summaries, and work records. |
| `tests/` | Legacy contract checks for the old harness, not current site acceptance. |
| `tools/` | Repo-local utilities; use only when their current scope is explicitly relevant. |
| `work/social/` | Campaign planning, research, and social-media scratch material. |

## Boundary

Keep this material inspectable because it shows the work, decisions, research,
and failures behind the project. Do not treat it as mandatory process for new
work unless Dídac explicitly reactivates that scope. The portfolio does not need
to copy repository evidence into `site/` for that evidence to remain part of ACB.
