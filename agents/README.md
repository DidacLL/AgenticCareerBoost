# agents/

This tree contains public proof material, historical working records, and a few
local helper scripts from ACB's evolution.

It is not a live agent harness. The active repository guidance is the root
`AGENTS.md` plus direct user instructions.

## How To Read This Tree

| Path | Current role |
|---|---|
| `cv/` | Public/general CV LaTeX source and build support. |
| `reports/` | Formal report sources and public proof documents. |
| `rules/` | Legacy harness design kept as evidence of previous system thinking. |
| `state/` | Historical logs, research, decisions, summaries, and work records. |
| `tests/` | Legacy contract checks for the old harness, not the current acceptance suite. |
| `tools/` | Small repo-local utilities used by the site/report workflow. |
| `work/social/` | Campaign planning, research, and social-media scratch material. |

## Boundary

Keep this material inspectable because it shows the work, decisions, research,
and failures behind the public project. Do not treat it as mandatory process for
new work unless Dídac explicitly reactivates that scope.
