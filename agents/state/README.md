# State And Evidence

This folder keeps selected historical state, research, decisions, and run
records for ACB.

It is evidence for the project, not an active command queue. The root
`AGENTS.md` and direct user instructions define current work.

## Main Files

- `current.md`, `active-sprint.md`, `roadmap.md`, `backlog.md`, and
  `human-actions.md` are compact historical state markers.
- `research/` keeps market, profile, positioning, relaunch, and failure-analysis
  research that explains the career strategy and repo evolution.
- `logs/` keeps representative run, decision, validation, remediation, and
  closure records.
- `archive/origin/` keeps initial bootstrapping evidence.
- `archive/audits/` keeps older external/audit material.
- `archive/low-signal-logs/` keeps verbose PairCheck, CI, option, and fragment
  logs that are preserved but no longer part of the main reading path.

## Curation Rule

Do not delete historical evidence casually. If a document is noisy but might
explain how the project evolved, move it to an archive path instead of removing
it from the repository.
